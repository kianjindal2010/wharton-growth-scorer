# Six Month Backtest Archive

This folder contains the frozen scoring inputs and outputs for the retrospective test described in `reports/Growth_Sleeve_Six_Month_Backtest_Report.docx`.

- Scoring date: 2026-03-20
- Performance end date: 2026-09-18
- Universe: 18 companies across US, Japan, United Kingdom, India, and Taiwan
- `backtest_results.csv`: compact company-level results
- `backtest_results.json`: method, aggregate statistics, company-level results, and failure log
- `snapshots/`: frozen scoring inputs used by the model

The statement data is period-filtered but not a fully point-in-time filing archive. Read the report limitations before interpreting the findings.
